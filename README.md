# PixelOdyssey
PixelOdyssey est un projet de vision par ordinateur, visant à détecter automatiquement les déchets plastiques à partir d'images de drone. En combinant des modèles de reconnaissance visuelle avec des données de terrain, PixelOdyssey permet de quantifier les déchets plastiques, dans le but de cartographier la pollution et de faciliter la collecte.
